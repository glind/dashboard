# Long-Term Memory (Template)

This file is a starter template for local, instance-specific memory.

## Important
- Copy this file to LONG_TERM_MEMORY.md on each new machine/instance.
- LONG_TERM_MEMORY.md is gitignored and must stay local.
- Do not commit personal notes, credentials, or private context.

## Identity
- Populate from user profile and recurring facts.

## Goals
- Track durable goals and recurring priorities.

## Preferences
- Capture likes, dislikes, and communication preferences.

## Work Style
- Record planning habits, work cadence, and scheduling patterns.

## Relationships
- Note important people, teams, and recurring stakeholders.

## Standing Instructions
- Save stable instructions the assistant should follow.

- YYYY-MM-DDTHH:MM:SS
